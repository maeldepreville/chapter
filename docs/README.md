# Chapter — Product and UI documentation

This directory preserves the decisions made during the progressive design of Chapter.

## Source of truth

[`CHAPTER_DECISIONS.md`](./CHAPTER_DECISIONS.md) is the transversal decision log. It records the validated roadmap, constraints, decisions, justifications and current phase.

## Conversation continuity

The repository-wide rules in [`../AGENTS.md`](../AGENTS.md) apply to every project chat. Before working, each conversation must read the transversal log and the document for the active phase. After every validated, refined, revised or abandoned design decision, it must update both documents before ending the turn. Chat history complements these files but never replaces them.
